📋 Introduction

LiveStill (« nous », « notre », « l'application ») respecte votre vie privée et s'engage à protéger vos données personnelles. Cette politique de confidentialité explique quelles données nous collectons, comment nous les utilisons, et vos droits concernant ces données. En utilisant LiveStill, vous acceptez les pratiques décrites dans cette politique.

📊 Données que Nous Collectons

1. Données personnelles

  • Nom d'utilisateur (optionnel) : vous pouvez choisir d'entrer un nom ou un pseudonyme pour personnaliser votre expérience (notamment pour que vos contacts d'urgence sachent de qui provient l'alerte). Cette donnée est stockée uniquement sur votre appareil.
  • Contacts d'urgence : vous désignez des personnes de confiance en enregistrant leur nom et numéro de téléphone. Ces contacts recevront une alerte SMS uniquement si vous n'avez pas effectué votre check-in « Je suis toujours là » dans le délai que vous avez configuré.

2. Données de bien-être

  • Journal d'humeurs : les émojis que vous sélectionnez (😊, 😢, 😔, etc.) — c'est facultatif : vous pouvez effectuer votre check-in sans choisir d'humeur ; la date et l'heure de chaque enregistrement.
  • Historique d'activité : date et heure de vos interactions avec le bouton « Je suis toujours là » ; fréquence d'utilisation de l'application.

3. Données techniques

  • Informations de connexion ; journaux techniques nécessaires au bon fonctionnement de l'application ; données de synchronisation avec notre serveur sécurisé.

Nous ne collectons PAS :

  • Votre localisation GPS
  • Vos contacts téléphoniques (sauf ceux que vous désignez explicitement)
  • Vos photos ou fichiers
  • Vos messages ou communications privées
  • Vos notes ou textes libres (l'application ne comporte pas de saisie de texte libre)
  • Informations bancaires ou de paiement

🎯 Comment Nous Utilisons Vos Données

Utilisation unique : fonctionnement de l'application. Vos données ne sont utilisées que pour :

  • Afficher votre historique personnel ; consulter votre journal d'humeurs ; visualiser vos statistiques de bien-être ; suivre votre évolution personnelle
  • Gérer vos contacts d'urgence (liste, modification, suppression)
  • Envoyer des alertes SMS : si vous n'avez pas effectué votre check-in « Je suis toujours là » dans le délai que vous avez configuré — uniquement aux contacts que vous avez désignés, avec un message personnalisé : le nom que vous avez renseigné est inclus dans le message, afin que le contact sache de qui provient l'alerte. Le contenu du message n'est pas modifiable par l'utilisateur.

Nous n'utilisons JAMAIS vos données pour :

  • Publicité ciblée ou marketing : aucune publicité dans l'application, aucun profil publicitaire créé
  • Revente ou partage commercial : vos données ne sont jamais vendues
  • Analyse comportementale ou profilage : pas de suivi de vos habitudes à des fins commerciales
  • Partage avec des réseaux sociaux : aucune connexion, aucun partage automatique

🔒 Stockage et Sécurité de Vos Données

  • 1. Stockage local (sur votre appareil) : journal d'humeurs, statistiques, préférences.
  • 2. Serveur backend sécurisé (Render.com) : hébergement dans des datacenters sécurisés (Europe/États-Unis), utilisé uniquement pour la fonctionnalité d'alerte SMS, connexion chiffrée HTTPS.
  • 3. Service SMS (Twilio) : utilisé uniquement au moment d'envoyer une alerte, conforme au RGPD, aucune conservation prolongée.

Pseudonymisation : chaque utilisateur est désigné par un code technique. Vos données personnelles (nom, humeurs) restent sur votre appareil et ne sont pas reliées à une identité sur nos serveurs.

Mesures de sécurité :

  • Chiffrement des communications : toutes les connexions utilisent le protocole HTTPS (SSL/TLS)
  • Accès restreint : seul le développeur a accès au serveur backend
  • Pas de conservation inutile : les données sont conservées uniquement le temps nécessaire ; suppression automatique si vous désinstallez l'application
  • Protection des identifiants : aucune exposition publique de clés sensibles

🤝 Services Tiers Utilisés

  • Twilio (envoi de SMS) : pour envoyer les alertes SMS à vos contacts d'urgence. Données partagées : les numéros de téléphone de vos contacts désignés, le contenu du message d'alerte. Politique : twilio.com/legal/privacy — Twilio est conforme au RGPD.
  • Render.com (hébergement du serveur) : pour héberger le serveur qui gère les alertes SMS. Données partagées : données techniques nécessaires au fonctionnement (logs serveur), aucune donnée personnelle stockée de manière permanente. Politique : render.com/privacy

🚫 Partage de Vos Données

Principe général : aucun partage commercial. Vos données ne sont jamais partagées, vendues ou louées à des tiers à des fins commerciales ou publicitaires.

  • Contacts d'urgence (avec votre consentement explicite) : uniquement les informations nécessaires (votre nom, message d'alerte). Vous contrôlez qui reçoit ces alertes.
  • Obligations légales : si requis par une autorité judiciaire compétente, pour se conformer à une loi applicable, pour protéger nos droits légaux.
  • Services techniques nécessaires : Twilio (envoi de SMS), Render.com (hébergement). Ces prestataires sont tenus par des accords de confidentialité stricts.

⚖️ Vos Droits sur Vos Données (RGPD)

Une architecture pensée pour votre vie privée : chaque utilisateur est désigné par un code technique. Nous ne stockons pas de données permettant d'identifier directement la personne physique derrière ce code : sur nos serveurs ne transitent que des codes techniques et les informations strictement nécessaires à l'envoi des alertes.

  • En raison de cette pseudonymisation, nous ne pouvons pas identifier la personne derrière un code, ni remettre une copie nominative de données personnelles.
  • Vous gardez le contrôle direct dans l'application : vous pouvez modifier ou supprimer vos informations, vos contacts d'urgence et votre journal à tout moment.
  • Suppression : vous pouvez demander la suppression de votre compte et des données associées à votre code, dans l'application ou en nous contactant.

Pour toute question concernant vos données, contactez-nous aux coordonnées indiquées en bas de cette page : nous répondons dans un délai maximum de 30 jours.

LiveStill n'est pas destiné aux enfants de moins de 13 ans et nous ne collectons pas sciemment de données personnelles d'enfants de moins de 13 ans. Conformément à la réglementation applicable (notamment l'article 8 du RGPD), l'âge du consentement numérique varie entre 13 et 16 ans selon les pays — il est fixé à 15 ans en France : si vous êtes mineur et que vous n'avez pas atteint l'âge requis dans votre pays de résidence, vous devez obtenir l'autorisation de vos parents ou de votre représentant légal avant d'utiliser l'application.
